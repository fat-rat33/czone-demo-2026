一个把**小队战术规则**搬进赛博废墟街区的 **3D** 战术游戏 Demo。

## 这一局是什么

- **战场**：C 区，**橙色**等级（发生混乱但仍可压制）。
- **棋盘**：**90" × 66"** —— C 区一整个街区：四个街角 + 中央十字路口 + 主街。
- **规则适配**：全员 **APL = 4**；**转移**每个激活可用 **2 次**（其余行动仍限 1 次）。
- **双方**：
  - **武装警察** 11 人：1 名警长（指挥）+ 6 名警员 + 2 名持盾警员 + 2 名特警狙击手。
  - **暴匪** 18 人：1 名煽动者 + 17 名暴徒（可用减员换装减到 14 人，换 4 件升级装备）。
  - 暴匪可用**最多 4 次减员换装**：每减 1 人，为另 1 人换更好的装备（突击步枪 / 霰弹枪 / 轻机枪 / 防弹背心）。
- **胜利**：4 个转折点结束后 VP 高者胜；控制目标标识得分（详细见游戏内"规则速查"）。

## 已实现的规则

**回合结构**
- 战斗 = 4 个转折点；每回合 = 战略阶段（拼骰定先手 → 发 CP → 就绪） + 交战阶段（交替激活）。
- 先手拼骰 + **先手权卡**（重投 / ±1 / ±2 / ±3），轮流打牌或让过；第 2 转折点起，拼骰败者按回合数拿卡。
- 平手：无先手权者获胜。

**激活**
- APL 上限、同激活内**同名行动不可重复**、AP 最低 0。
- 命令：交战（可射击/冲锋/反应）、隐匿（不能射击/冲锋/反应，**有掩护时不是有效目标**）。
- **反应**：己方全员待机而对手还有就绪时，可选一名待机+交战特工免费执行 1 个行动（移动 ≤2"）。

**行动**
- 转移（移动属性，分段向上取整）、冲刺（3"）、后撤（2AP，脱离交战）、冲锋（+2"，须在敌方 1" 内结束）、射击、近战、拾取/放置标识。

**射击（按官方附录 10 步）**
- 判定阻碍 → 掩护（目标 1" 内的阻碍地形，且距离 >2"）→ 遮挡（重型地形、不在任一方 1" 内）
- 有效目标判定（可见 / 交战 / 隐匿无掩护 / 制高点特殊情形）
- 精准 1 / 2（高差 ≥2" / ≥4"）、攻击骰、6 关键 1 失败、穿刺扣防御骰、掩护豁免
- 防御 3 骰、抵挡（2 普通挡 1 关键）、结算伤害

**近战**
- 同时掷、从攻方开始轮流"出击/格挡"、协助每名 +1 命中。

**其它**
- 耐伤 / 受伤 / 受创（-2" 移动、命中 -1）、残废移出。
- 标识争夺与控制（APL 总和）、每转折点结算 VP、每路 op 封顶 6VP。
- 击杀等级（按对手起始人数查表）。

## 3D 场景与模型

- **模型全部由 Blender 程序化生成**（`tools/build_models.py`，Blender 5.2 headless）：4 种店铺（便利店/诊所/加油站/修理厂）、公交、轿车、路障、沙袋、垃圾箱、瓦砾、两种制高点平台，以及 8 种特工（警察 4 / 暴匪 4）。
- **1 Blender 单位 = 1 英寸**，与 `data.js` 完全同尺度；模型导出后按碰撞矩形的 `w × h` 精确缩放到对应地块，所以**碰撞盒就是模型的占地**。
- 按 **B** 可以看到绿色线框：那是引擎真正用于寻路/视线/放置的矩形，和模型外轮廓一致。
- 重建模型：
  ```bash
  blender -b -P tools/build_models.py   # 生成 assets/models/*.glb + manifest.json
  node tools/pack_models.js             # 打包成 assets/models/models.js（file:// 也能加载）
  ```
- 场景：程序化地面贴图（沥青/车道线/裂缝/水洼/地面涂鸦）、方向光 + 半球光 + 街道暖光 + 霓虹补光、带阴影；单位头顶有 P/R 阵营徽标，脚下是阵营色底盘环与选中光环。

## 人机对战

编成页底部可以切 **单人 vs 电脑**：

| 选项 | 说明 |
|---|---|
| 你执 | 警方 / 暴匪，另一边交给电脑 |
| 电脑难度 | **新手**：不用指挥重掷、不找掩体、残血也不撤<br>**老兵**：会花 CP 重掷关键骰、移动时找掩体、残血后撤<br>**凶狠**：更早压上、更爱贴脸，其余同老兵 |
| 节奏 | 标准 / 快速 ×1.5（同时放大移动与射程） |

电脑会自动完成：部署 → 选主要行动 op → 逐次激活（转移可以连用两次、射击、冲锋、反应、后撤）→ 跳过激活。
它行动时底部会显示「电脑思考中…」，地图点击被锁住，轮到你才恢复。

直接用 URL 开一局人机：
```
index.html?vs=ai&level=ruthless&human=rioters
```

想看电脑互打：`index.html?debug=autoplay`。

## 警戒 / 哨戒 / 掩护

| 状态 | 触发时机 | 效果 |
|---|---|---|
| **警戒**（Overwatch） | 敌方单位**移动途中**进入自己的射界 | 立刻打断这次移动，花预留的 1 AP 射击一次；之后转交战 |
| **哨戒**（Sentry） | 自己被敌方**射击 / 冲锋 / 近战**锁定 | 花预留的 1 AP 先冲刺 3"，躲开这次攻击 |
| **掩护**（Cover） | 友军移动触发了敌方的警戒 | 花预留的 1 AP 向那名敌方警戒者射击；之后转交战 |

- 三种状态都花 1 AP 进入，**进入时必须还剩 1 AP**（预留触发用）；同一单位同时只能有一种。
- **触发是可选的**：条件满足时会弹出「开火 / 放过」的询问（电脑按难度自己决定）；放过则不消耗预留点，被打断的移动会继续走完。
- **警戒打断移动后移动停住**（不继续前进）。
- 触发后消耗预留的 1 AP，状态清除；警戒/掩护触发后命令立刻变成**交战**。
- 每转折点结束时所有警戒状态清空。

## 存档与继续

- 每完成一个行动、结束一次激活、以及每 15 秒自动存一次（localStorage，键 `czone.save.v1`）
- 标题页「继续游戏」一键回到上次局面（含编成时的武器/装备选择）
- 新开局会自动清掉旧存档；存档带版本号，版本不符会拒绝读取而不是崩溃
- 存档内容：转折点、阶段、先后手、双方 VP/击杀/CP、全部单位（位置/伤势/AP/命令/装备状态）、目标点、烟雾与火场、最近 40 条战斗日志

## 目标点

| 类型 | 数量 | 位置 | 判定 |
|---|---|---|---|
| **中央补给站**（常驻） | 1 | 地图中央 | 控制半径 **3 寸**；每转折点控制方 +1VP |
| **一次性拾取点** | 4 | 每局随机（保证可达） | 走到 1 寸内花 1 AP 拾取 → **+2VP**，随即消失 |

**争夺规则**（双方都在圈内时）：

- 只有一方在圈内 → 该方控制
- 双方都在圈内 → 比"控制力"：**每人算 APL（4）+ 装备加成（无人机/通讯/侦察 +1）**，且**最多只计 3 人**（防止人海堆人）
- 控制力相同 → **争夺中，无人得分**，下个转折点重新判定

## 装备

编成页每名特工右侧有「装备」按钮，打开 25 件装备的选择面板（警方 19 件 / 暴匪 14 件，强度差由装备补）。

| 类别 | 内容 |
|---|---|
| 投掷物（12 种） | 破片手雷、烟雾弹、震撼弹、催泪弹、EMP、燃烧弹、燃烧瓶、土制炸弹、钉子弹、眩晕弹、标记弹、捕捉网 |
| 通讯 | 战术电台（给友军 +1 AP）、信号干扰器（敌方 CP-1） |
| 侦察 | 热成像扫描仪（无视隐匿掩护）、测距仪（射程 +3"、精准 +1） |
| 无人机 | 侦察 / 护盾 / 攻击无人机（警方专属） |
| 医疗 | 急救包（回 2 伤）、兴奋剂包（首次受伤免疫） |
| 护具 | 防弹插板（豁免 +1）、光学迷彩（12" 外无法被锁定）、**袖章**（暴匪专属，全队限 3：被击杀时保留 1 血并白送一次 1 AP 动作，每局一次） |
| 工具 | 工程工具（开门翻窗免 AP） |

**配额**：每人最多 3 件投掷物 + **1 件常驻装备**；全队投掷物总数 ≤ 队内人数（警方 13 / 暴匪 18）。袖章全队限 3 件。

**主动效果**：
- 攻击无人机：1 AP，12" 内 A2 4+ 射击，每转折点一次
- 侦察无人机：1 AP，标记敌人使其本回合无法获得掩护
- 护盾无人机：被动，3" 内友军获得掩护
- 信号干扰器：被动，敌方每回合 CP 获取 -1
- 通讯 / 无人机 / 侦察装备：控制点权重 +1（警方以装备补人数劣势的核心机制）

## 规则改动（相对参考规则）

| 项 | 原规则 | 本作 |
|---|---|---|
| APL | 各数据卡不同（2～3） | **全员 4** |
| 转移 | 每激活 1 次（同名行动不可重复） | **每激活最多 2 次**（其余行动仍 1 次） |
| 棋盘 | 30"×22" | **90"×66"**（完整街区，6 个目标点） |

这三处是为了让"整街区 + 多人对抗"的节奏成立：APL 4 让单位能在一次激活里"移动→移动→射击"或"移动→射击→转移"，转移两次则可以跨过一个街区。
